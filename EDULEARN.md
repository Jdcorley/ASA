## What Is This?

A complete **mobile-first interactive education app** inspired by Brilliant.org. Designed to be developed and tested entirely from your phone with zero configuration needed.

## Getting Started

```bash
cd edu-app
npm install
npm run dev
```

Then open the displayed Network URL on your phone!

## Features

- 📱 **Mobile-First** - Optimized for touch and phone screens
- 🎮 **Interactive** - Sliders, quizzes, flashcards, animations
- 🎨 **Beautiful** - Modern gradients, smooth animations, dark mode
- 📚 **4 Complete Lessons** - Math, Science, English, Physics
- 🔧 **6 Ready Components** - Question cards, sliders, progress rings, etc.
- 📖 **Well Documented** - 5 comprehensive guides included
- ⚡ **Instant Updates** - Hot reload for immediate feedback
- 🌐 **PWA Ready** - Installable as an app on phones

## What's Included

### Sample Lessons
1. **Mathematics** - Interactive multiplication with visual groups
2. **Science** - Flashcards for scientific concepts  
3. **English** - Grammar and vocabulary quiz
4. **Physics** - Projectile motion simulator with real-time animation

- LessonCard - Subject cards with progress tracking
- QuestionCard - Multiple choice questions
